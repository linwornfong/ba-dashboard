🎯 4. Brand DNA

🧬 Brand Pillars

🎓 สื่อสร้างสรรค์เพื่อการเรียนรู้ 🔬 วิทยาศาสตร์ + ความสนุก 👨‍👩‍👧 เด็ก + ครอบครัว + ครู 🌏 มาตรฐานสากล เข้าถึงคนไทย 🏆 รางวัลนานาชาติ 🚀 Multi-format

🎤 Be STEAM Manifesto

"BESTEAM เปิดโลเคชั่นแชร์เส้นทางการรับ ความรู้แนวใหม่ ที่กำลังฮิตติดเทรนด์ โดนใจทุกเพศทุกวัย ลูกเด็กเล็กแดง ตาสีตาสา ยายมียายมา ที่น่าสนใจและกำลังมาแรง ในโลกยุคสังคมโซเชี่ยล ด้วยส่วนผสมของสาระความรู้ แนวคิดแปลกๆ มันส์ๆ ตลกเฮฮา แถมจุดประกายไอเดียความสร้างสรรค์ โดยไม่มีคำว่าเป็นไปไม่ได้"

🎨 Tone of Voice / โทนเสียง

  • สนุก แต่สาระ — แอบสอนวิทยาศาสตร์แบบไม่รู้ตัว
  • ตื่นเต้น + ใกล้ตัว — สัตว์/แมลง/ปรากฏการณ์ที่พบเห็นในชีวิตจริง
  • ตั้งคำถามก่อนสอน — "เชื่อไหม...?", "มนุษย์กินชีสมากแค่ไหนถึงตุย?"
  • ฮีโร่ของเด็กธรรมดา — "เด็กไทยทำได้" (Proud เว่อร์)
  • ความเห็นอกเห็นใจ — "เด็กแต่ละคนมีความแตกต่าง แต่ทุกคนมีคุณค่า" (JIGSAW)

💎 5. SWOT Analysis

💪 STRENGTHS • จุดแข็ง

  • Library ใหญ่ที่สุดในไทย: 2,591 ตอน ใน 27 programs
  • 585M+ views บน YouTube — 44 คลิป viral 1M+
  • รางวัลนานาชาติ 29+: Japan Prize, ABU, Prix Jeunesse, IPST
  • 20+ ปีประสบการณ์ + ทีมผู้บริหาร 4 คน
  • Co-production 3 ประเทศ: 🇰🇷 EBS, 🇯🇵 NHK, 🇩🇪 Goethe
  • Multi-platform: TV + YouTube + FB + TikTok + LINE
  • 2 Flagships: บ้านวิทย์ (218M) + H2OH (230M) = 76% views

⚠️ WEAKNESSES • จุดอ่อน

  • ขาด Teen content 13-18: มีแค่ TIC TAC TECH + ภารกิจพิชิตฝัน
  • ไม่มี Interactive/Live/AR-VR/Podcast
  • Brand awareness: คนไทยรู้จักรายการ แต่ไม่รู้จัก Be Amazing
  • เว็บไซต์เก่า: beamazing.co.th ไม่ค่อย update

💡 8. Strategic Ideas & Open Opportunities

🔴 Priority #1: เร่ง Pipeline กลับเข้า 200+ ตอน/ปี

ปัญหา: Pipeline ลด 80% (271 → 51 ตอน)

แนวทาง: AI/automation ตัดต่อ + repurposing content เก่าเป็น Shorts/Clip

Quick win: เอา 1,094 ตอนเก่าของ "บ้านนักวิทย์น้อย" + 195 ตอนของ "H2OH" ตัดเป็น Shorts (60s) → 2,500+ Shorts ใหม่

🔴 Priority #2: เปิด "AI Lab" รายการใหม่

โอกาส: AI Literacy = mega-trend 2026+ — ไม่มีเจ้าของตลาด

Format: เด็ก 10-15 ปี เรียน AI ผ่านเกม + โปรเจกต์จริง

🔴 Priority #3: License "บ้านนักวิทย์น้อย" + "H2OH" ไปอาเซียน

Asset: 2 Flagships = 1,289 ตอน 449M views เป็นหลักฐานว่า content ดี

Revenue model: License fee + Royalty 5-10% ต่อตอน

🟡 Priority #4: เปิด Interactive Live + AR App

แนวทาง: Live streaming ทดลองวิทยาศาสตร์ + ให้เด็กโหวตผ่านแอป

🟡 Priority #5: ขยาย Teen Segment (13-18 ปี)

Gap: มีแค่ TIC TAC TECH + ภารกิจพิชิตฝัน — Teen ตลาดใหญ่ แต่ยังไม่ครอบคลุม

แนวทาง: รายการใหม่ "Real Teen" — เด็กวัยรุ่นแก้ปัญหาจริง

🟡 Priority #6: ขยาย Events เป็น Franchise

แนวทาง: Franchise "Be Amazing Camp" — ขาย license ให้ รร.

🟢 Priority #7: เปิด "Be Amazing Podcast"

Gap: ไม่มี audio-first content

🟢 Priority #8: Merchandise / Character Licensing

Asset: ตัวละครจาก "บ้านนักวิทย์น้อย" + "H2OH" → License ของเล่น/เสื้อผ้า
